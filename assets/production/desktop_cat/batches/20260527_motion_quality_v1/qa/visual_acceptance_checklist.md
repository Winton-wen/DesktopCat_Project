# Visual Acceptance Checklist

Batch: `20260527_motion_quality_v1`

Target actions:

- `happy`
- `cute`
- `sleep_in`
- `wake`
- `walk`
- `walk_left`

## Hard Reject

- [ ] Cat flattens, melts, collapses, or changes body volume unnaturally.
- [ ] Paw appears or disappears suddenly.
- [ ] Ear, paw, tail, bow, or bell is cropped.
- [ ] Pose jumps directly from one extreme to another.
- [ ] Action depends on only two key poses with no visible in-betweens.
- [ ] Character identity drifts from the locked kitten design.

## Happy

- [ ] Has anticipation before the paw lift.
- [ ] Paw lift is smooth across multiple frames.
- [ ] Expression brightens gradually.
- [ ] Has a small bounce or overshoot.
- [ ] Settles cleanly back to idle.

## Cute

- [ ] Has a readable cute pose or expression change.
- [ ] Motion uses several in-between frames.
- [ ] Tilt or bounce does not look like a rigid sticker wobble.
- [ ] Returns cleanly to idle.

## Sleep In

- [ ] Starts with sleepy eyes or slow blink.
- [ ] Head lowers before the body settles.
- [ ] Paws tuck or relax naturally.
- [ ] Body keeps plush volume and does not flatten.
- [ ] End frame matches the sleep loop.

## Wake

- [ ] Eyes open before the body rises.
- [ ] Front paws visibly push the body up.
- [ ] Ears and tail have delayed secondary motion.
- [ ] Ends close to idle without a snap.

## Walk / Walk Left

- [ ] Alternating paws are readable.
- [ ] Body bob is subtle and periodic.
- [ ] Tail, bow, and bell have small delayed motion.
- [ ] Loop is seamless.
- [ ] Direction matches the action name.
