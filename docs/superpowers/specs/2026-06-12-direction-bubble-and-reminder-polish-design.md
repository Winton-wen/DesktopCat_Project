# DesktopCat 方向、气泡与提醒按钮修复设计

## 目标

修复人工巡演发现的四类问题，使正式礼物运行时与视觉巡演保持一致：

- 左右菜单动作不再与文案方向相反；
- happy 在正式运行和巡演中都按同一规则随机选择方向；
- 四条颜文字文案不再从颜文字中间换行；
- 提醒按钮改为柔和浅蓝色。

## 方向行为

右键菜单的“向左走两步”和“向右走两步”属于明确方向命令。它们必须保持指定方向，即使猫位于对应屏幕边缘，也只能停止水平移动并原地播放该方向动作，不能自动反向。

随机待机走动仍允许在屏幕边缘自动转向，以保证自主动作不会持续撞向屏幕外。

## Happy 行为

正式“开心一下”继续随机选择左右方向；位于边缘时由现有安全边界逻辑改为朝屏幕内部跳。

视觉巡演不再直接播放固定的 `happy` 动作。每次进入 happy 条目或按 `R` 重播时，都调用正式运行时的 happy 方向准备方法，因此可在巡演中验证随机方向。

## 气泡与巡演标签

巡演的 `[17/53] source_id · category · action` 标签移出真实气泡，放进独立置顶状态窗口。真实气泡只显示收件人最终会看到的文案，确保换行结果与礼物版一致。

以下四条文案显式插入换行：

```text
{pet_name}会乖乖安静地陪着{mama_nickname}
꜀(^. .^꜀  )꜆੭
```

```text
已经很晚啦，{mama_nickname}早点休息呀
꜀(^. .^꜀  )꜆੭
```

```text
{mama_nickname}辛苦一天啦，{pet_name}来贴贴你
꜀(^. .^꜀  )꜆੭
```

```text
{mama_nickname}还没睡嘛，{pet_name}好心疼{mama_nickname}
(｡í _ ì｡)，{mama_nickname}忙完就早点休息吧。
```

## 提醒按钮

提醒按钮统一使用：

- 普通背景：`#DCEEFF`
- 悬停背景：`#C4E2FF`
- 文字颜色：`#28527A`

按钮窗口背景与按钮普通背景一致。正式提醒与巡演提醒共用同一组件，因此同时生效。

## 测试

测试覆盖：

- 明确向左/向右命令在边缘不反向；
- 随机走动仍可在边缘转向；
- 正式 happy 和巡演 happy 使用同一方向准备方法；
- 巡演气泡不包含巡演标签，独立状态视图收到标签；
- 四条文案包含预期换行且颜文字完整；
- 提醒按钮使用确认的三种浅蓝配色；
- 完整测试和 GUI smoke 通过。

- 不恢复 stash，不处理 `raw/wake_*`。
