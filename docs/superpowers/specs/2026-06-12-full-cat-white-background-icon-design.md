# DesktopCat 白底完整猫猫图标设计

日期：2026-06-12

## 目标

替换当前由透明动画帧裁切出的猫头图标。新图标使用
`参考图/1.png` 中的完整坐姿猫猫，保留原图白色背景，使 Windows 桌面图标
具有与普通应用图标接近的视觉大小，并避免透明抠图造成的残边。

## 构图

- 来源固定为 `参考图/1.png`。
- 保留耳朵、脸、蝴蝶结、前爪、后爪和尾巴。
- 使用居中的正方形裁切，不进行透明抠图或人工遮罩。
- 猫猫主体在 512 x 512 图标画布中占据约 88%-94% 的高度。
- 四周保留少量白边，避免耳朵和尾巴紧贴图标边缘。
- 输出保持不透明白色背景。

## 输出

- `assets/gift/desktopcat_icon_head_preview.png`：512 x 512 实际图标预览。
- `assets/gift/desktopcat_icon_size_preview.png`：16、24、32、48、64 px
  的桌面尺寸对比预览。
- `assets/gift/desktopcat.ico`：包含 16、24、32、48、64、128、256 px。

为避免影响已有构建脚本，继续使用现有文件名，即使预览文件名中仍保留
`head`。

## 验收

- 预览四角为白色且完全不透明。
- 猫猫不是透明小贴图，主体视觉高度接近整个图标。
- 16-64 px 下仍能辨认大眼睛、橘白配色和蝴蝶结。
- ICO 包含全部规定尺寸。
- 重新构建后的 EXE 使用新图标。
